## Runbook (once credentials exist)

1. `pip install "cdsapi>=0.7.7" netCDF4` (or xarray)
2. Configure `~/.cdsapirc` (url `https://cds.climate.copernicus.eu/api`, personal
   token) — **never commit or echo the token**.
3. In the CDS user profile, accept the Terms of Use for **both** datasets:
   `reanalysis-era5-single-levels-monthly-means` and
   `derived-era5-single-levels-daily-statistics`.
4. `python3 copernicus_pilot_fetch.py` (CDS queue latency can be hours; daily
   statistics are computed at retrieval time and are not archived).
5. `python3 copernicus_pilot_checks.py` → inspect `copernicus_pilot_report.json`.
   Any FAIL invalidates the ERA5 Primary contract until corrected.
